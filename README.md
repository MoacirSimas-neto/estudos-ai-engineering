## Sobre a trilha

Este repositório documenta, de forma pública e organizada, a minha evolução em **AI Engineering**. Sou estudante de Ciência da Computação na UNIVALI e estou direcionando minha carreira para desenvolvimento de software com IA, agentes de IA e automações empresariais.

> **Aviso:** este repositório registra estudos e experimentos em andamento. Ele **não** representa domínio avançado de todos os assuntos listados. Cada item só é marcado como concluído quando eu realmente finalizo o curso ou o laboratório.

Os cursos seguidos são os **cursos oficiais** de cada empresa. Nenhum material protegido dos cursos é reproduzido aqui: o repositório guarda apenas links, progresso e o que eu mesmo produzo (laboratórios e anotações próprias).

## Objetivos profissionais

- Construir bases sólidas em **LLMs, APIs de modelos, agentes de IA, MCP e RAG**.
- Aprender a projetar automações confiáveis, com aprovação humana, segurança e monitoramento.
- Transformar o que estudo em **projetos demonstráveis**, como o [AI Dev World](https://github.com/MoacirSimas-neto/AI-DEV-WORD).
- Manter engenharia de software e bancos de dados como fundamento técnico.
